# RD Design Homepage V17

V17 is based directly on V16. The overall design is unchanged. This revision only enlarges and rebalances the two `Who We Are` story cards so all client-provided information is visible without being cut off.

## Run locally

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
4. If an older version is cached, use **Ctrl + F5**.

## Vercel

This remains a static HTML/CSS/JavaScript project. Use:

- Framework Preset: `Other`
- Root Directory: `./`
- Build Command: blank
- Output Directory: blank
- Install Command: blank
- Environment Variables: none required for the current preview
